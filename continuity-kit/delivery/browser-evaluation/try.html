A SHORT PRODUCT TRIAL

Your app can disappear.
Your work can have a way back.

Change a note, take the original app offline, then recover the exact saved correction from a separate client.

1. Open the workspace ↗Open recovery client ↗

This launcher prepares a public demo checkpoint. No wallet, real passkey or blockchain transaction is involved. Use invented text only. Stopping the launcher erases this trial.

  1. 1

    Make a correction.

    In the workspace choose Open existing workspace. Change Working draft, then Save checkpoint. Look for verified v2.

  2. 2

    Lose the original app.

    Expand Demonstration tools. Choose Mirror 1 serves an old valid copy, then Take primary offline. Close the workspace tab.

  3. 3

    Bring the note back.

    Open the recovery client fresh. Choose Recover demo workspace. Check for your exact correction, verified v2 and rejection of the old copy.

Try a failure, too
  1. In the recovery client's Demonstration tools choose Both mirrors serve an old valid copy.
  2. Choose Discard this session & reload, then recover again. The old version must not be presented as current.
  3. Repeat with Registry unavailable. The app should report that it cannot check freshness.
  4. Restore Both copies healthy and Bring primary back, or restart the launcher for a fresh trial.
What is worth evaluating?

Would this protect work you change regularly? Would an independent encrypted export already be enough? Is the extra recovery setup and version check worth it?

Both encrypted copies still share one local service. This demo does not establish independent hosting, real device compatibility, demand or an integration with another product. An old valid copy is not automatically the current one; the version check depends on a trusted registry being available.

Setup and troubleshooting

Run npm ci --ignore-scripts --no-audit --no-fund, then npm start in the extracted package using Node.js 24+. Keep the terminal running. Ports 4373–4375 must be free. The package accepts no physical/testnet flags and reads no .env file.

This trial uses ordinary desktop browser tabs. If the hostname does not resolve to loopback in your environment, note the environment and stop; changing to another origin changes the recovery policy. Read README.md for the full steps and EVALUATION_NOTES.md for feedback.
